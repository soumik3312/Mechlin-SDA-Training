## 4. Challenges and Lessons Learned

### 4.1 Development Environment and Compatibility

Working across multiple development frameworks required careful management of SDK versions, dependencies and environment configurations.

**Lesson learned:** Verify tool versions and project requirements before making environment changes.

### 4.2 Backend and Frontend Integration

Frontend and backend applications must agree on request formats, response structures and data types.

**Lesson learned:** API contracts, validation and consistent data mapping are essential.

### 4.3 AI Service Integration

Connecting multiple AI services required understanding gateway communication, service availability and request forwarding.

**Lesson learned:** A modular architecture makes it easier to connect and troubleshoot separate services.

### 4.4 Docker Networking and Persistence

Containerized applications need correct network configuration and persistent storage.

**Lesson learned:** Containers and persistent volumes have different lifecycles. Application data should not depend on the lifetime of a single container.

### 4.5 Git and Collaborative Workflow

Working with feature branches, commits, remote repositories and pull requests helped develop a structured approach to version control.

**Lesson learned:** Small, focused commits and careful staging reduce accidental changes.
